# Драйвер IMU

## MSUROVERTEAM-IMU

Драйвер Инерциального Измерительного Датчика (IMU) (WITMOTION WT901BLECL BLE5.0) с возможностью калибровки акселерометра и гироскопа.

### Структура проекта

* **MSUROVERTEAM-IMU/**
    * **resource/**
    * **launch/**
        * `wt901_wit.launch.py` — основной **launch-файл** для ROS 2 Humble 
    * **test/** — автоматизированные тесты.
        * `test_copyright.py` — автоматизированный тест на проверку наличия лицензий и авторских прав (copyright) в исходном коде программного обеспечения.
        * `test_flake8.py` — автоматизированный тест на соответствие стандартам оформления кода (Code Style).
        * `test_pep257.py` — автоматизированный тест для проверки наличия и правильности документации в исходном коде Python.
    * **eureka_imuwt901/**
        * **__pycache__/**
        * `__init__.py`
        * `wt901_calibration.py` — узел конфигурации и калибровки датчика WT901.
        * `wt901_node_Andrei.py` — образец низкоуровневого драйвера для инерциального датчика WT901, который переводит низкоуровневые байты из последовательного порта в стандартные сообщения ROS2 
        * `wt901_node.py` — драйвер для IMU-сенсора WT901 на базе ROS2, который преобразует "сырые" данные из последовательного порта (Serial) в стандартные сообщения ROS2. Это законченный узел, который позволяет получать наклон, повороты и ускорение ровера, используя датчик WT901.
        * `basic_reader.py` —  улучшенная и более полная версия драйвера ROS 2 для датчика WT901, которая работает по принципу активного опроса регистров.
        * `tester_integrator.py` — узел инерциальной одометрии. Его главная задача — на основе данных драйвера `wt901_node.py` вычислить пройденное расстояние и текущее положение робота в пространстве.
        * `solution.py` — высокоуровневый драйвер инерциальной навигации, который выполняет три критически важные задачи:
		    *  Собирать в одном узле данные акселерометра, гироскопа, магнитометра и углов ориентации.
			*  Благодаря калибровке и матричным вычислениям в реальном времени, узел вычитает ускорение свободного падения из показаний. Это позволяет получить чистое линейное ускорение самого робота без влияния силы тяжести.
			*  Все данные публикуются в стандартных сообщениях (`Imu`, `MagneticField`) с корректными метками времени и системами координат (`frame_id`), что позволяет сразу использовать этот узел в пакетах навигации (`robot_localization`).
    * `setup.py` — сценарий установки драйвера IMU, сборочный файл для Python-пакета в системе ROS2, который позволяет Python-скриптам драйвера IMU работать как узлы ROS2.
    * `setup.cfg`
    * `package.xml`

###  Определение узлов

**Блок калибровки (calibration_node)**

```bash																																																										
calibration_node = Node(
    package='eureka_imuwt901',           # Имя пакета
    executable='wt901_calibration_node', # Имя запускаемого файла
    name='wt901_calibration_node',       # Имя узла в системе ROS
    output='screen'                      # Вывод логов в терминал
)
```

Этот узел отвечает за калибровку датчика WT901 перед началом работы. Для калибровки необходимо снять комментарий в строке `#calibration_node`.

**Основной рабочий узел (main_node)**

```bash
main_node = TimerAction(
    period=1.0, 
    actions=[
        Node(
            package='eureka_imuwt901',
            executable='wt901_node',
            name='wt901_node',
            output='screen'
        )
    ]
)
```

Драйвер cчитывает данные с IMU и публикует их в топики ROS2. Основной узел запускается через 1 сек. после запуска launch-файла.

**Основные функции файла установки `setup.py`**

*   Определение имени и структуры пакета `eureka_imuwt901`, (все файлы кроме файлов из папки `test`).
*   Установка служебных файлов (Data Files), регистрация пакета в индексе `ament` и  устанавливака всех файлов из папки launch (заканчивающихся на .launch.py). 
*   Создание исполняемых узлов (Entry Points):
    *   `wt901_calibration_node` — запускает калибровку,
	*   `wt901_node` — запускает основной драйвер датчика,
	*   `solution` — запускает высокоуровневый драйвер инерциальной навигации.
	
Взаимодействие драйвера IMU с ROS2 Humble, другими плагинами и нодами ведется через стандартизированный интерфейс сообщений.
